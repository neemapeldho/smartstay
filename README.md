📘 SmartStay Estimator — Machine Learning Airbnb Price Predictor

SmartStay Estimator is a machine-learning powered web application that predicts Airbnb-style property prices based on host, property, and review details.
Built using Python, Streamlit, scikit-learn, and a modern neon glass-theme UI, the app provides real-time price predictions in INR.

🚀 Features
   =========

🧹 Data cleaning, preprocessing, and feature engineering

🔠 Categorical encoding using LabelEncoder

📏 Feature scaling using StandardScaler

🤖 Linear Regression model for price prediction

🌐 Interactive Streamlit web interface

🎛️ Clean sliders, dropdowns, and user-friendly inputs

💰 Real-time price prediction converted to INR

✨ Modern neon dark UI (glassmorphism + gradients)
